# Ch.11: The Environment (환경)

## 오늘 배울 것

오늘은 **셸 환경**이 뭔지 배울 거야. 셸이 동작할 때 참고하는 설정값들 — 환경변수, 셸 변수, 그리고 시작할 때 자동으로 읽는 설정 파일들을 알아볼 거야. 이걸 알면 `PATH`가 뭔지, `.bashrc`가 뭔지 이해할 수 있어!

---

## 셸 변수 vs 환경변수

이 둘의 차이가 핵심이야:

- **셸 변수**: `VAR="값"` — 현재 셸에서만 존재. 다른 프로그램에게는 안 보여.
- **환경변수**: `export VAR="값"` — 자식 프로세스에게도 전달됨!
- **삭제**: `unset VAR`

**주의**: `=` 앞뒤에 공백 넣으면 안 돼!
```bash
VAR="값"     # ✅ 올바름
VAR = "값"   # ❌ 에러! (VAR을 명령어로 해석함)
```

---

## 환경 확인 명령어

지금 어떤 변수들이 설정되어 있는지 보고 싶으면:

- `printenv` — 환경변수 전체 목록
- `printenv HOME` — 특정 환경변수 확인
- `echo $HOME` — 같은 결과를 이렇게도 볼 수 있어
- `set` — 셸 변수 + 환경변수 + 함수까지 전부 표시
- `export` — export된 변수 목록

---

## 자주 쓰는 환경변수

이건 알아두면 좋아:

| 변수 | 의미 |
|------|------|
| `HOME` | 내 홈 디렉토리 |
| `USER` | 현재 사용자 이름 |
| `PATH` | 명령어를 찾는 경로 목록 |
| `SHELL` | 현재 쓰는 셸 |
| `LANG` | 언어/로케일 설정 |
| `PWD` | 현재 디렉토리 |
| `EDITOR` | 기본 에디터 |

## PATH — 명령어를 어디서 찾아?

`ls`를 치면 셸이 `/usr/bin/ls`를 실행하잖아. 어떻게 찾는 거냐면, **PATH에 적힌 디렉토리들을 순서대로** 뒤져서 찾는 거야.

```bash
echo $PATH
# /usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin
```

`:` 로 구분된 디렉토리 목록이야. **왼쪽부터 순서대로** 탐색해서 찾으면 실행, 못 찾으면 `command not found`!

### PATH에 새 경로 추가하기

```bash
export PATH="$PATH:/새경로"       # 뒤에 추가 (기존 것 먼저 찾음)
export PATH="/새경로:$PATH"       # 앞에 추가 (새 경로를 먼저 찾음)
```

앞에 넣으면 우선순위가 높아지고, 뒤에 넣으면 낮아져.

---

## 스타트업 파일 — 셸이 시작할 때 읽는 설정

셸이 시작되면 자동으로 설정 파일들을 읽어. 두 가지 경우가 있어:

- **로그인 셸**: `/etc/profile` → `~/.bash_profile` (또는 `~/.profile`)
- **비로그인 셸**: `~/.bashrc`

보통 `.bash_profile`이 `.bashrc`를 호출하게 설정되어 있어서, 결국 둘 다 실행되는 구조야.

### 설정 바꾼 후 적용하기

`.bashrc`를 수정했으면 터미널을 새로 열거나, 이렇게 하면 돼:

```bash
source ~/.bashrc     # 설정 파일 다시 읽기
# 또는
. ~/.bashrc          # source의 줄임말
```

---

## 정리

오늘 배운 핵심:
- **셸 변수** = 현재 셸에서만, **환경변수** = `export`하면 자식 프로세스에도 전달
- `=` 앞뒤에 공백 넣으면 안 돼!
- `PATH` = 명령어를 찾는 디렉토리 목록 (왼쪽부터 순서대로 탐색)
- 셸 시작 시 `.bash_profile`과 `.bashrc`를 자동으로 읽음
- 설정 바꾸면 `source ~/.bashrc`로 적용
