# Ch.14: Customizing the Prompt

## 오늘 배울 것

터미널 프롬프트 — `[me@linuxbox ~]$` 이거 있잖아. 이걸 **내 맘대로 꾸밀 수 있어**! 색깔도 넣고, 시간도 넣고, 2줄로 만들 수도 있어.

---

## PS1 — 프롬프트를 저장하는 환경변수

프롬프트는 `PS1`이라는 환경변수에 저장되어 있어:

```bash
echo $PS1              # 현재 프롬프트 확인
PS1="새프롬프트> "     # 바로 변경 가능 (현재 세션만)
```

영구적으로 바꾸려면 `.bashrc`에 `export PS1="값"`을 추가하면 돼.

## 이스케이프 코드 — 특수 정보 넣기

`\` 뒤에 특정 글자를 넣으면 셸이 알아서 변환해줘:

| 코드 | 의미 | 예시 |
|------|------|------|
| `\u` | 유저명 | `dam` |
| `\h` | 호스트명 (짧은 버전) | `DESKTOP-U33LE6V` |
| `\H` | 호스트명 (전체) | `DESKTOP-U33LE6V.local` |
| `\w` | 현재 경로 (전체) | `~/Documents/project` |
| `\W` | 현재 디렉토리명만 | `project` |
| `\d` | 날짜 | `Mon Feb 18` |
| `\t` | 시간 (24시간, HH:MM:SS) | `14:30:25` |
| `\T` | 시간 (12시간, HH:MM:SS) | `02:30:25` |
| `\@` | 시간 (12시간, AM/PM) | `02:30 PM` |
| `\n` | 줄바꿈 | |
| `\$` | `$` 또는 `#` (일반/root 구분) | |

## 색상 넣기

형식: `\[\033[코드m\]내용\[\033[00m\]`

### 색상 코드

| 코드 | 색상 |
|------|------|
| `0;31` | 빨강 |
| `0;32` | 초록 |
| `0;33` | 노랑 |
| `0;34` | 파랑 |
| `0;35` | 보라 |
| `0;36` | 청록 |
| `01;3X` | **굵게** + 해당 색 |
| `00` | 리셋 (색 끄기) |

### 반드시 지켜야 할 규칙 2가지

1. 색상 코드는 **`\[...\]`로 감싸야 해**
   - bash에게 "이건 화면에 안 보이는 문자야"라고 알려주는 거야
   - 빠지면 긴 명령어 칠 때 줄바꿈이나 커서 위치가 깨져

2. 색을 넣은 후 **`\[\033[00m\]`로 리셋** 필수
   - 안 하면 색이 계속 번져서 뒤에 오는 모든 텍스트에 색이 적용돼

## PS2

`PS2`는 줄이 이어질 때 나오는 프롬프트야 (기본값: `>`):

```bash
echo "hello
> world"          # ← 이 > 가 PS2
```

---

## 실전 예시

```bash
# 기본 형태
PS1="\u@\h:\w\$ "
# 결과: dam@DESKTOP-U33LE6V:/home/dam$

# 색상 + 시간
PS1="\[\033[01;31m\][\t]\[\033[00m\] \[\033[01;34m\]\w\[\033[00m\]\$ "
# 결과: [14:30:25] /home/dam$ (빨간 시간 + 파란 경로)

# 2줄 프롬프트
PS1="\[\033[01;32m\]\u@\h\[\033[00m\]\n\[\033[01;34m\]\w\[\033[00m\] \$ "
# 결과:
# dam@DESKTOP-U33LE6V    (초록)
# /home/dam $             (파랑)
```

---

## 정리

오늘 배운 핵심:
- 프롬프트는 `PS1` 환경변수에 저장
- `\u`(유저), `\h`(호스트), `\w`(경로), `\t`(시간) 등 이스케이프 코드
- 색상: `\[\033[코드m\]내용\[\033[00m\]` 형식
- `\[...\]`로 감싸기 + 마지막에 리셋 — 이 두 가지 규칙 필수!
- 영구 적용하려면 `.bashrc`에 추가
