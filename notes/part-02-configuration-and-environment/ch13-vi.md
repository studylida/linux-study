# Ch.13: A Gentle Introduction to vi

## 오늘 배울 것

오늘은 **vi(vim)** 에디터를 배울 거야. nano보다 확실히 어렵지만, 거의 모든 리눅스/유닉스 시스템에 기본 설치되어 있어서 서버 작업할 때 꼭 알아야 해. 한번 익숙해지면 nano보다 훨씬 빠르게 편집할 수 있어!

---

## vi vs vim

- **vi** = Visual Editor (1976년, Bill Joy가 만듦)
- **vim** = Vi IMproved (vi의 업그레이드 버전)
- 대부분의 리눅스에서 `vi`를 치면 실제로는 vim이 실행돼

---

## 핵심: 3가지 모드

vi를 어렵게 만드는 원인이 바로 이 **모드** 시스템이야. 근데 이걸 이해하면 나머지는 쉬워:

```
         ┌──────────────┐
   Esc   │              │  i, a, o 등
  ┌──────│  Normal Mode  │──────┐
  │      │  (기본 모드)   │      │
  │      └──────────────┘      │
  │             │    ▲         ▼
  │          : (콜론) │   ┌──────────────┐
  │             │  Esc│   │ Insert Mode  │
  │             ▼     │   └──────────────┘
  │      ┌──────────────┐
  └─────▶│ Command Mode │
         └──────────────┘
```

| 모드 | 용도 | 어떻게 들어가? |
|------|------|----------------|
| Normal | 이동, 삭제, 복사, 붙여넣기 | `Esc` |
| Insert | 텍스트 입력 (글 쓰는 모드) | `i`, `a`, `o` 등 |
| Command | 저장, 종료, 찾기/바꾸기 | `:` (콜론) |

**원칙: 헷갈리면 `Esc`!** — Normal Mode로 돌아가니까 안전해.

---

## 열기 / 저장 / 종료

```bash
vi filename        # 파일 열기
```

| 명령 | 동작 |
|------|------|
| `:w` | 저장 (write) |
| `:q` | 종료 (quit) |
| `:wq` | 저장하고 종료 |
| `:q!` | 저장 안 하고 강제 종료 (변경사항 버림) |
| `ZZ` | 저장하고 종료 (Normal Mode에서, : 없이) |

---

## 커서 이동 (Normal Mode)

### 기본 이동 — hjkl

방향키도 되지만, vi의 정석은 hjkl이야:

```
         k (위)
          ▲
h (왼쪽) ◄─┼─► l (오른쪽)
          ▼
         j (아래)
```

### 빠른 이동

| 키 | 동작 |
|----|------|
| `0` | 줄 맨 앞 |
| `$` | 줄 맨 끝 |
| `w` | 다음 단어 (word) |
| `b` | 이전 단어 (back) |
| `gg` | 파일 맨 처음 |
| `G` | 파일 맨 끝 |
| `숫자G` | 해당 줄로 이동 (예: `10G` = 10번째 줄) |

---

## Insert Mode 진입 — 글을 쓰려면

Normal Mode에서 이 키를 누르면 Insert Mode로 바뀌어:

| 키 | 어디에서 입력 시작? | 기억법 |
|----|---------------------|--------|
| `i` | 커서 앞 | insert |
| `a` | 커서 뒤 | append |
| `o` | 아래에 새 줄 | open line |
| `I` | 줄 맨 앞 | 대문자 = 강화 버전 |
| `A` | 줄 맨 뒤 | 대문자 = 강화 버전 |
| `O` | 위에 새 줄 | 대문자 = 반대 방향 |

글 쓰기 끝나면 `Esc`로 Normal Mode로 돌아와.

---

## 삭제 (Normal Mode)

| 키 | 동작 |
|----|------|
| `x` | 글자 1개 삭제 |
| `dd` | 줄 전체 삭제 |
| `dw` | 단어 삭제 |
| `d$` | 줄 끝까지 삭제 |
| `d0` | 줄 처음까지 삭제 |
| `3dd` | 3줄 삭제 (숫자 + 명령어 조합) |

---

## 복사 & 붙여넣기 (Normal Mode)

| 키 | 동작 |
|----|------|
| `yy` | 줄 복사 (yank) |
| `yw` | 단어 복사 |
| `p` | 커서 뒤에 붙여넣기 |
| `P` | 커서 앞에 붙여넣기 |
| `3yy` | 3줄 복사 |

그리고 `dd`로 삭제한 건 사실 **잘라내기**야. `dd` + `p` = 줄 이동!

---

## 실행 취소

| 키 | 동작 |
|----|------|
| `u` | undo (되돌리기) |
| `Ctrl-r` | redo (다시 실행) |

---

## 찾기 (Normal Mode)

| 키 | 동작 |
|----|------|
| `/단어` | 아래 방향으로 검색 |
| `?단어` | 위 방향으로 검색 |
| `n` | 다음 검색 결과 |
| `N` | 이전 검색 결과 |

---

## 찾기 & 바꾸기 (Command Mode)

```
:%s/찾을단어/바꿀단어/g     # 파일 전체에서 전부 바꾸기
:%s/찾을단어/바꿀단어/gc    # 하나씩 확인하며 바꾸기 (y/n 선택)
```

- `%` = 파일 전체 범위
- `s` = substitute (치환)
- `g` = global (한 줄에 여러 번 나와도 전부)
- `c` = confirm (하나씩 확인)

---

## 정리

오늘 배운 핵심:
- vi는 **3가지 모드**: Normal(기본), Insert(입력), Command(저장/종료)
- **헷갈리면 `Esc`!**
- `:wq` = 저장하고 종료, `:q!` = 저장 안 하고 나가기
- `i`로 Insert Mode 진입, `Esc`로 돌아오기
- `dd` = 줄 삭제, `yy` = 줄 복사, `p` = 붙여넣기
- `u` = undo, `Ctrl-r` = redo
- `:%s/찾기/바꾸기/g` = 전체 치환
