# Ch.4: Manipulating Files and Directories

## 오늘 배울 것

오늘은 파일과 디렉토리를 **만들고, 복사하고, 옮기고, 삭제하는** 방법을 배울 거야. 리눅스 작업의 핵심이야! 그리고 여러 파일을 한 번에 다루는 **와일드카드**도 배울 거야.

---

## 핵심 명령어 5개

| 명령어 | 하는 일 |
|--------|---------|
| `mkdir` | 디렉토리 만들기 |
| `cp` | 복사 |
| `mv` | 이동 또는 이름 변경 |
| `rm` | 삭제 |
| `ln` | 링크 만들기 |

---

## 와일드카드 (Wildcards) — 여러 파일을 한 번에!

파일 이름을 하나하나 치는 건 귀찮잖아. 와일드카드를 쓰면 **패턴에 맞는 파일들을 한 번에** 지정할 수 있어:

| 와일드카드 | 의미 | 예시 |
|------------|------|------|
| `*` | 아무 문자든 0개 이상 | `*.txt` = 모든 txt 파일 |
| `?` | 정확히 1개 문자 | `file?.txt` = file1.txt, fileA.txt |
| `[abc]` | 괄호 안 문자 중 하나 | `file[123].txt` |
| `[!abc]` | 괄호 안 문자 제외 | `file[!0-9].txt` |
| `[[:class:]]` | 문자 클래스 | `[[:upper:]]*` |

### 문자 클래스 — 더 확실한 방법

`[A-Z]*`로 대문자로 시작하는 파일을 찾을 수 있긴 한데, 시스템 언어 설정(로케일)에 따라 결과가 달라질 수 있어. **문자 클래스**를 쓰면 어느 시스템에서든 확실하게 동작해:

| 클래스 | 의미 |
|--------|------|
| `[[:alnum:]]` | 알파벳 + 숫자 |
| `[[:alpha:]]` | 알파벳만 |
| `[[:digit:]]` | 숫자만 |
| `[[:lower:]]` | 소문자 |
| `[[:upper:]]` | 대문자 |
| `[[:space:]]` | 공백 문자 |
| `[[:punct:]]` | 구두점 |

```bash
ls [[:upper:]]*              # 대문자로 시작하는 파일
ls *[[:digit:]]*             # 숫자가 포함된 파일
ls [[:digit:]][[:digit:]]*   # 숫자 두 개로 시작하는 파일
```

## mkdir — 디렉토리 만들기

```bash
mkdir dir1 dir2 dir3          # 여러 개 한꺼번에 만들기
mkdir -p parent/child/grandchild  # 중첩 디렉토리를 한 번에!
```

`-p` 옵션이 핵심이야. 이게 없으면 `parent`가 없을 때 에러가 나는데, `-p`를 붙이면 **중간 경로도 자동으로 만들어줘**.

---

## cp — 복사

```bash
cp file1 file2                # file1을 file2로 복사
cp file1 dir1/                # file1을 dir1 안으로 복사
cp -r dir1 dir2               # dir1 전체를 dir2로 복사
```

주요 옵션:
| 옵션 | 의미 |
|------|------|
| `-i` | 덮어쓰기 전에 물어봄 (interactive) |
| `-r` | 디렉토리 전체 복사 (recursive) |
| `-u` | 더 새로운 파일만 복사 (update) |
| `-v` | 뭘 복사하는지 보여줌 (verbose) |

**주의**: `-r` 없이는 디렉토리를 복사할 수 없어! 에러 나.

---

## mv — 이동/이름 변경

`mv`는 **두 가지 역할**을 해:

```bash
mv file1 file2                # 이름 변경 (같은 위치)
mv file1 dir1/                # 다른 곳으로 이동
mv dir1 dir2                  # 디렉토리 이름 변경 또는 이동
```

주요 옵션:
| 옵션 | 의미 |
|------|------|
| `-i` | 덮어쓰기 전에 물어봄 |
| `-u` | 더 새로운 파일만 이동 |
| `-v` | 뭘 옮기는지 보여줌 |

`cp`와 달리 `mv`는 디렉토리도 **`-r` 없이** 바로 이동/이름 변경이 가능해.

---

## rm — 삭제 (주의!)

```bash
rm file1                      # 파일 삭제
rm -r dir1                    # 디렉토리 전체 삭제
rm -rf dir1                   # 강제 삭제 (물어보지도 않음!)
```

주요 옵션:
| 옵션 | 의미 |
|------|------|
| `-i` | 삭제 전에 물어봄 |
| `-r` | 디렉토리 전체 삭제 (recursive) |
| `-f` | 강제 삭제, 경고 없음 (force) |
| `-v` | 뭘 삭제하는지 보여줌 |

**정말 중요한 거**: 리눅스에는 **휴지통이 없어!** `rm`으로 지우면 그냥 사라져. 그래서 삭제 전에 `ls`로 먼저 확인하는 습관이 중요해.

## ln — 링크 만들기

```bash
ln file1 file1-hard           # 하드 링크
ln -s file1 file1-sym         # 심볼릭 링크
```

### 하드 링크 vs 심볼릭 링크

| | 하드 링크 | 심볼릭 링크 |
|---|----------|-------------|
| 원본 삭제하면? | 데이터 살아있음 | 링크 깨짐 |
| 디렉토리에 쓸 수 있나? | 불가 | 가능 |
| 다른 디스크 간? | 불가 | 가능 |

### 하드 링크 vs 복사(cp)

| | cp (복사) | ln (하드 링크) |
|---|----------|---------------|
| 데이터 | 새로 복제됨 | 같은 데이터를 공유 |
| 디스크 용량 | 2배 사용 | 추가 용량 없음 |
| 한쪽 수정하면? | 각자 따로 | 둘 다 같이 바뀜 |

실무에서는 대부분 **심볼릭 링크**(`ln -s`)를 써. 하드 링크는 특수한 상황에서만 쓰여.

---

## 정리

오늘 배운 핵심:
- `mkdir -p`로 중첩 디렉토리 한 번에 만들기
- `cp -r`로 디렉토리 복사 (`-r` 필수!)
- `mv`는 이동과 이름 변경을 둘 다 함
- `rm`은 영구 삭제 — 휴지통 없음!
- **와일드카드**(`*`, `?`, `[...]`)로 여러 파일 한 번에 지정
- **심볼릭 링크**(`ln -s`)가 실무에서 더 많이 쓰임
