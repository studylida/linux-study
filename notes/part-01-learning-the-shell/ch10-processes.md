# Ch.10: Processes (프로세스)

## 오늘 배울 것

오늘은 **프로세스** — 실행 중인 프로그램을 관리하는 방법을 배울 거야. 어떤 프로그램이 돌아가고 있는지 확인하고, 백그라운드에서 실행하고, 응답 없는 프로그램을 강제 종료하는 방법까지!

---

## 프로세스란?

```
프로그램 = 파일 (디스크에 저장된 코드)
프로세스 = 실행 중인 프로그램 (메모리에 올라간 상태)
```

같은 프로그램을 2개 열면 프로세스도 2개 생겨. 각 프로세스에는 **PID(Process ID)**라는 고유 번호가 붙어서 구분할 수 있어.

---

## 프로세스 확인하기

```bash
ps            # 현재 터미널의 프로세스만 보기
ps aux        # 시스템 전체 프로세스 보기 (가장 많이 씀!)
top           # 실시간 모니터링 (q로 나가기)
```

### ps aux에서 중요한 컬럼

- **USER**: 누가 실행했는지
- **PID**: 프로세스 고유 번호
- **%CPU / %MEM**: CPU/메모리 얼마나 쓰는지
- **COMMAND**: 어떤 명령어인지

---

## 백그라운드 / 포그라운드

터미널에서 프로그램을 실행하면 끝날 때까지 기다려야 하잖아. 근데 **백그라운드**로 보내면 뒤에서 돌리면서 다른 작업을 할 수 있어!

```bash
sleep 100 &     # 처음부터 백그라운드에서 실행 (& 붙이기)
jobs            # 백그라운드 작업 목록 보기
fg %1           # 1번 작업을 포그라운드(앞)로 가져오기
bg %1           # 정지된 작업을 백그라운드에서 재개
Ctrl+Z          # 실행 중인 프로그램 일시 정지
Ctrl+C          # 실행 중인 프로그램 종료
```

### 흐름 정리

```
명령어 &     → 백그라운드에서 바로 실행
Ctrl+Z       → 일시 정지 (멈춤)
bg %번호     → 정지된 걸 백그라운드에서 재개
fg %번호     → 포그라운드로 가져오기
```

### 주의: fg/bg는 jobs 번호, kill은 PID!

이거 헷갈리면 안 돼:
- **fg, bg** → `jobs` 번호 사용 → `fg %1`
- **kill** → PID 사용 → `kill 12345`

---

## 프로세스 종료

```bash
kill 12345        # 종료 요청 (정상 종료 — 정리할 시간을 줌)
kill -9 12345     # 강제 종료 (즉시 죽임! 최후의 수단)
killall firefox   # 이름으로 전부 종료
```

`kill`은 기본적으로 "제발 종료해줘"라고 **요청**하는 거야. 근데 프로그램이 안 들으면? 그때 `-9`를 써서 강제로 죽이는 거지.

---

## 실전에서 자주 쓰는 패턴

```bash
ps aux | grep 이름     # 특정 프로세스 찾기
top                     # 뭐가 CPU 잡아먹는지 실시간으로 확인
kill -9 PID             # 응답 없는 프로세스 강제 종료
```

---

## 정리

오늘 배운 핵심:
- **프로그램** = 파일, **프로세스** = 실행 중인 프로그램 (PID로 구분)
- `ps aux`로 전체 프로세스 확인, `top`으로 실시간 모니터링
- `&`로 백그라운드 실행, `Ctrl+Z`로 정지, `fg`/`bg`로 전환
- `kill PID` = 종료 요청, `kill -9 PID` = 강제 종료 (최후의 수단)
- fg/bg는 **jobs 번호**(`%1`), kill은 **PID** 사용!
