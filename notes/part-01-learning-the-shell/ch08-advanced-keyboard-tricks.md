# Ch.8: Advanced Keyboard Tricks (키보드 고급 트릭)

## 오늘 배울 것

오늘은 터미널에서 **타이핑 속도를 확 올려주는 단축키들**을 배울 거야. 마우스 없이 키보드만으로 빠르게 명령어를 편집하고, 이전에 쳤던 명령어를 순식간에 찾아 쓸 수 있어!

---

## 커서 이동 단축키

긴 명령어를 쳤는데 앞쪽을 수정해야 할 때, 화살표를 꾹 누르고 있으면 답답하지? 이 단축키를 쓰면 순간이동이야:

| 단축키 | 동작 | 외우는 법 |
|--------|------|-----------|
| `Ctrl-A` | 줄 맨 앞으로 | A = 알파벳의 처음 |
| `Ctrl-E` | 줄 맨 끝으로 | E = End |
| `Ctrl-B` / `Ctrl-F` | 한 글자 뒤로 / 앞으로 | B = Back, F = Forward |
| `Alt-B` / `Alt-F` | 한 **단어** 뒤로 / 앞으로 | 단어 단위 이동 |

가장 많이 쓰는 건 `Ctrl-A`(맨 앞)와 `Ctrl-E`(맨 끝)야!

## 텍스트 편집 단축키

| 단축키 | 동작 |
|--------|------|
| `Ctrl-D` | 커서 위치의 글자 삭제 |
| `Ctrl-T` | 커서 앞 두 글자 교환 (오타 수정에 좋음) |
| `Alt-T` | 커서 앞 두 **단어** 교환 |
| `Alt-L` / `Alt-U` | 소문자 / 대문자로 변환 |

## Kill & Yank (잘라내기 & 붙여넣기)

터미널에서는 "잘라내기"를 **Kill**, "붙여넣기"를 **Yank**라고 해:

| 단축키 | 동작 |
|--------|------|
| `Ctrl-K` | 커서부터 **줄 끝까지** 잘라내기 |
| `Ctrl-U` | 커서부터 **줄 처음까지** 잘라내기 |
| `Alt-D` | 커서부터 **단어 끝까지** 잘라내기 |
| `Alt-Backspace` | 커서부터 **단어 처음까지** 잘라내기 |
| `Ctrl-Y` | 마지막으로 잘라낸 텍스트 붙여넣기 |

예를 들어 긴 명령어의 뒷부분을 통째로 지우고 싶으면? `Ctrl-K` 한 번이면 끝!

## 자동완성 (Tab) — 게임 체인저

Tab 키는 진짜 많이 써. 타이핑을 획기적으로 줄여줘:

```bash
ls /etc/ho[Tab]       # → ls /etc/hostname (파일명 완성)
sys[Tab][Tab]         # → sys로 시작하는 명령어 목록 표시
echo $HO[Tab]         # → echo $HOME (변수도 완성!)
```

- **Tab 1번**: 자동완성 (후보가 하나면 바로 완성)
- **Tab 2번**: 후보가 여러 개면 목록 표시

## 히스토리 — 이전 명령어 재활용

| 단축키/명령어 | 동작 |
|--------------|------|
| `↑` / `Ctrl-P` | 이전 명령어 |
| `↓` / `Ctrl-N` | 다음 명령어 |
| `Ctrl-R` | **역방향 검색** (가장 유용!) |
| `Ctrl-G` / `Ctrl-C` | 검색 취소 |
| `history` | 전체 히스토리 보기 |
| `history \| grep ssh` | 특정 명령어 검색 |

### Ctrl-R — 이전 명령어를 검색으로 찾기

`Ctrl-R`을 누르면 검색 모드가 되는데, 글자를 치면 **가장 최근에 그 글자가 포함된 명령어**를 찾아줘. 예를 들어 어제 쳤던 긴 ssh 명령어를 다시 치고 싶으면 `Ctrl-R` 누르고 `ssh`만 치면 돼!

### 히스토리 확장 — ! 사용하기

```bash
!!        # 직전 명령어 재실행
!123      # 히스토리 123번 재실행
!ssh      # ssh로 시작하는 마지막 명령어 재실행
sudo !!   # 직전 명령어를 sudo로 재실행 (실전에서 자주 씀!)
```

`sudo !!`는 진짜 자주 써. "아 이거 sudo 빼먹었네!" 할 때 바로 `sudo !!` 치면 돼.

## 기타 유용한 단축키

| 단축키 | 동작 |
|--------|------|
| `Ctrl-L` | 화면 지우기 (`clear`와 같음) |
| `Ctrl-C` | 현재 실행 중인 명령 취소 |
| `Ctrl-D` | EOF 전송 (빈 줄에서 누르면 셸 종료) |

---

## 정리

오늘 배운 핵심:
- `Ctrl-A`/`Ctrl-E`로 줄 맨 앞/끝으로 순간이동
- `Ctrl-K`/`Ctrl-U`로 한 방에 잘라내기, `Ctrl-Y`로 붙여넣기
- **Tab**으로 자동완성 — 타이핑 줄이는 최고의 방법
- **Ctrl-R**로 이전 명령어 검색 — 긴 명령어 다시 칠 필요 없음
- `sudo !!` = "아까 그거 sudo로 다시!" — 실전에서 자주 씀
