# Ch.1: What Is the Shell?

## 오늘 배울 것

오늘은 리눅스의 가장 기본인 **셸(Shell)**이 뭔지 알아볼 거야. 이게 뭔지 모르면 리눅스를 쓸 수가 없거든!

---

## 셸(Shell)이 뭐야?

셸은 **키보드로 명령어를 입력하면 운영체제에 전달해주는 프로그램**이야. 쉽게 말하면 너와 리눅스 사이의 **통역사** 같은 거지.

대부분의 리눅스 배포판은 **bash**라는 셸을 기본으로 쓰는데, 이게 **B**ourne-**A**gain **SH**ell의 줄임말이야. Steve Bourne이라는 사람이 만든 원조 Unix 셸(`sh`)의 업그레이드 버전이라고 보면 돼.

---

## 터미널 에뮬레이터

"그럼 셸은 어떻게 여는 거야?" — GUI(그래픽) 환경에서는 **터미널 에뮬레이터**라는 프로그램을 열어서 셸과 대화해.

- KDE 환경이면 `konsole`
- GNOME 환경이면 `gnome-terminal` (보통 메뉴에서 "Terminal"이라고 되어 있어)

macOS의 Terminal.app이나 iTerm2도 같은 역할을 하는 터미널 에뮬레이터야.

---

## 셸 프롬프트 읽는 법

터미널을 열면 이런 게 보여:

```
[me@linuxbox ~]$
```

이게 **프롬프트(prompt)**인데, 각 부분의 의미는 이래:

- `me` — 사용자 이름 (나)
- `linuxbox` — 컴퓨터(호스트) 이름
- `~` — 현재 위치 (홈 디렉토리라는 뜻)
- `$` — 일반 사용자라는 표시

만약 `$` 대신 `#`이 보이면? 그건 **root(관리자)**로 로그인된 거야. 조심해야 해!

---

## 첫 번째 명령어들을 쳐보자

셸에 명령어를 치면 결과가 바로 나와. 하나씩 해보자:

```bash
date          # 현재 날짜와 시간이 나와
cal           # 이번 달 달력이 출력돼
df            # 디스크 여유 공간을 보여줘
free          # 메모리 사용량을 보여줘 (리눅스에서만 작동)
exit          # 터미널 세션 종료 (Ctrl+D도 같은 효과)
```

간단하지? `date` 치면 날짜 나오고, `cal` 치면 달력 나오고. 리눅스는 이렇게 **명령어 하나하나가 하나의 기능**을 담당해.

---

## 알아두면 편한 기능들

### 명령어 히스토리

위쪽 화살표(↑)를 누르면 **이전에 쳤던 명령어**가 다시 나와! 아래쪽 화살표(↓)로 다음 명령어로 이동할 수도 있어. 리눅스는 보통 최근 1000개 명령어를 기억해줘.

### 커서 이동

명령어를 치다가 오타가 났으면? 좌우 화살표(←→)로 커서를 이동해서 수정할 수 있어.

### 복사 & 붙여넣기

여기서 중요한 거! 터미널에서는 `Ctrl+C`, `Ctrl+V`가 복사/붙여넣기가 **아니야**. 터미널에서 이 키들은 완전히 다른 의미로 쓰여.

- **복사**: 마우스 왼쪽 버튼으로 드래그하면 자동 복사
- **붙여넣기**: 마우스 가운데 버튼 클릭

---

## 가상 콘솔 (Virtual Console)

GUI 뒤에서 텍스트 전용 터미널 세션들이 숨어있어:

- `Ctrl+Alt+F1` ~ `Ctrl+Alt+F6` — 가상 콘솔 접근
- `Alt+F7` — 다시 그래픽 화면으로 돌아오기

서버 관리할 때나 GUI가 멈췄을 때 유용하게 쓸 수 있어.

---

## 정리

오늘 배운 핵심:
- **셸** = 명령어를 운영체제에 전달하는 프로그램 (bash가 가장 흔함)
- **터미널 에뮬레이터** = GUI에서 셸을 쓰게 해주는 프로그램
- **프롬프트**의 `$`는 일반 사용자, `#`은 root
- `date`, `cal`, `df`, `free` 같은 기본 명령어
- 화살표 키로 히스토리 탐색 가능
