# Ch.2: Navigation

## 오늘 배울 것

리눅스에서 **디렉토리(폴더)를 돌아다니는 방법**을 배울 거야. 이건 진짜 매일 쓰는 기본 중의 기본이야!

---

## 리눅스 파일 시스템 구조

윈도우에서는 `C:\`, `D:\` 같은 드라이브가 있잖아? 리눅스는 달라. **모든 것이 하나의 트리**에서 시작해. 그 꼭대기가 바로 **루트(`/`)**야.

```
/
├── bin      ← 필수 실행 파일들
├── etc      ← 설정 파일들
├── home     ← 사용자들의 홈 디렉토리
│   └── me   ← 내 홈 디렉토리
├── usr      ← 사용자 프로그램들
└── ...
```

USB를 꽂든, 외장하드를 연결하든, 전부 이 트리 어딘가에 붙어. 윈도우처럼 별도 드라이브로 보이지 않아.

---

## 핵심 명령어 3개

이 3개만 알면 리눅스 안에서 돌아다닐 수 있어:

| 명령어 | 하는 일 | 예시 |
|--------|---------|------|
| `pwd` | 지금 내가 어디에 있는지 출력 | `/home/me` |
| `ls` | 여기에 뭐가 있는지 보여줘 | `ls /usr` |
| `cd` | 다른 곳으로 이동 | `cd /home` |

`pwd`는 **P**rint **W**orking **D**irectory의 줄임말이야. "내 현재 위치 알려줘!"라는 뜻이지.

---

## 경로(Path) — 주소를 쓰는 두 가지 방법

### 절대 경로 (Absolute Path)

루트(`/`)에서 시작하는 **전체 주소**야. 어디서 쳐도 같은 곳을 가리켜.

```bash
cd /home/me/Documents/file.txt
```

집 주소를 "서울시 강남구 역삼동 123번지"라고 쓰는 것과 같아.

### 상대 경로 (Relative Path)

**지금 내가 있는 위치**를 기준으로 쓰는 주소야. 현재 위치에 따라 의미가 달라져.

```bash
cd Documents/file.txt
```

"여기서 오른쪽으로 가면 돼"라고 말하는 거랑 같아 — 내가 어디 있느냐에 따라 다르잖아.

---

## 특수 디렉토리 표기

이건 외워두면 정말 편해:

| 표기 | 의미 | 예시 |
|------|------|------|
| `.` | 현재 디렉토리 | `./script.sh` (여기에 있는 스크립트 실행) |
| `..` | 상위(부모) 디렉토리 | `cd ..` (한 칸 위로) |
| `~` | 내 홈 디렉토리 | `cd ~/Documents` |
| `-` | 방금 전에 있었던 디렉토리 | `cd -` (이전 위치로 돌아가기) |

특히 `cd -`는 진짜 많이 써. 두 폴더를 왔다 갔다 할 때 아주 편해!

---

## cd 명령어 활용법

```bash
cd                  # 홈 디렉토리로 이동 (cd ~ 와 같음)
cd ~                # 홈 디렉토리로 이동
cd /usr/bin         # 절대 경로로 이동
cd Documents        # 현재 위치에서 Documents로 이동
cd ..               # 한 칸 위로
cd ../..            # 두 칸 위로
cd -                # 이전 디렉토리로 돌아가기
```

그냥 `cd`만 치면 홈 디렉토리로 가. 어디서든 집으로 돌아가는 셈이지!

## 파일/디렉토리 이름 규칙

리눅스에서 알아둬야 할 이름 규칙들:

1. **대소문자 구분** — `File.txt`와 `file.txt`는 **다른 파일**이야!
2. **숨김 파일** — `.`으로 시작하는 파일은 숨김 처리돼 (`.bashrc` 같은 거)
3. **공백 허용** — 가능하긴 한데 따옴표가 필요해서 불편해: `"my file.txt"`
4. **확장자** — 리눅스는 확장자로 파일 유형을 결정하지 않아. 내용으로 판단해.

---

## 정리

오늘 배운 핵심:
- 리눅스는 **단일 파일 트리** — 모든 게 `/`에서 시작
- `pwd` = 현재 위치, `ls` = 내용 보기, `cd` = 이동
- **절대 경로**(`/`로 시작)와 **상대 경로**(현재 위치 기준)
- `~` = 홈, `..` = 상위, `-` = 이전 위치
