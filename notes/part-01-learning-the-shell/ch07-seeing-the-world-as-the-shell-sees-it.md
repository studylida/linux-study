# Ch.7: Seeing the World as the Shell Sees It (셸의 눈으로 세상 보기)

## 오늘 배울 것

오늘은 좀 신기한 걸 배울 거야. 우리가 명령어를 치면 셸이 **바로 실행하는 게 아니라**, 특수 문자를 먼저 해석하고 변환한 뒤에 실행해. 이 과정을 **확장(Expansion)**이라고 해. 이걸 이해하면 셸이 왜 그렇게 동작하는지 감이 와!

```
너의 입력 → [셸의 확장 처리] → 실제 실행되는 명령어
```

---

## 확장의 7가지 종류

### 1. 경로명 확장 (Pathname Expansion)

`*`이나 `?` 같은 와일드카드가 실제 파일명으로 바뀌는 거야:

```bash
echo *.txt        # .txt로 끝나는 파일들이 쫙 나옴
echo .[!.]*       # 숨김 파일들 (.과 ..은 제외)
```

### 2. 틸드 확장 (Tilde Expansion)

`~`가 홈 디렉토리 경로로 바뀌는 거:

```bash
echo ~            # /home/사용자명
echo ~root        # /root
```

### 3. 산술 확장 (Arithmetic Expansion)

셸에서 바로 계산을 할 수 있어:

```bash
echo $((2 + 2))       # 4
echo $((100 / 3))     # 33 (정수만! 소수점 없어)
echo $((5**2))        # 25 (거듭제곱)
echo $((11 % 3))      # 2 (나머지)
```

### 4. 중괄호 확장 (Brace Expansion)

이건 정말 편해! 패턴으로 여러 문자열을 한 번에 만들 수 있어:

```bash
echo {A,B,C}-file     # A-file B-file C-file
echo file-{1..5}      # file-1 file-2 file-3 file-4 file-5
echo {01..10}         # 01 02 03 ... 10 (제로패딩도 됨!)
```

실전에서 이렇게 쓰면 진짜 편해:

```bash
mkdir -p project/{src,docs,tests}     # 디렉토리 3개 한 번에!
cp config.yml{,.bak}  # → cp config.yml config.yml.bak (백업 만들기)
```

**주의: 쉼표 뒤에 공백 넣으면 안 돼!**
```bash
echo {a, b}    # 확장 안 됨
echo {a,b}     # 확장됨!
```

### 5. 매개변수 확장 (Parameter Expansion)

환경변수 값을 가져오는 거:

```bash
echo $USER    # 현재 사용자명
echo $HOME    # 홈 디렉토리
echo $PATH    # 실행 경로
```

### 6. 명령어 치환 (Command Substitution)

명령어의 실행 결과를 문자열처럼 쓸 수 있어:

```bash
echo "오늘: $(date +%Y-%m-%d)"
file_list=$(ls /usr)
```

### 7. 단어 분리 (Word Splitting)

이건 조심해야 하는 부분이야:

```bash
name="hello world"
touch $name       # "hello"와 "world" 두 파일이 생김!
touch "$name"     # "hello world" 한 파일이 생김
```

따옴표를 안 쓰면 공백 기준으로 잘려버려!

## $()와 $(())의 차이

이 둘을 헷갈리면 안 돼:

| 문법 | 이름 | 용도 | 예시 |
|------|------|------|------|
| `$()` | 명령어 치환 | 명령어를 **실행**해서 출력을 가져옴 | `$(date)` → `2026-02-12` |
| `$(())` | 산술 확장 | **수학 계산** 결과를 가져옴 | `$((2+3))` → `5` |

```bash
echo "사용자: $(whoami)"        # 명령어 실행
echo "파일 수: $(ls | wc -l)"   # 명령어 실행

echo "합계: $((100 + 200))"     # 수학 계산
echo "나눗셈: $((10 / 3))"     # 수학 계산

echo $(date)     # date 명령어 실행
echo $((date))   # date를 숫자로 계산하려고 함 → 에러!
```

## 따옴표 (Quoting) — 확장을 제어하는 방법

### 큰따옴표 `" "` — $ 계열 확장만 허용

```bash
echo "사용자: $USER"          # 변수 확장 O
echo "날짜: $(date)"          # 명령어 치환 O
echo "합계: $((1+2))"         # 산술 확장 O
echo "*.txt"                   # 경로명 확장 X → 그대로 출력
echo "{a,b}"                   # 중괄호 확장 X → 그대로 출력
```

### 작은따옴표 `' '` — 모든 확장 차단

```bash
echo '$USER'       # → $USER (그대로 나옴)
echo '$(date)'     # → $(date) (그대로 나옴)
```

### 이스케이프 `\` — 한 글자만 보호

```bash
echo "가격: \$100"    # → 가격: $100
```

### 따옴표별 확장 동작 정리표

| 확장 종류 | 따옴표 없음 | `" "` | `' '` |
|-----------|:-----------:|:-----:|:-----:|
| 경로명 `*` `?` | O | X | X |
| 틸드 `~` | O | X | X |
| 중괄호 `{a,b}` | O | X | X |
| 산술 `$(())` | O | O | X |
| 매개변수 `$변수` | O | O | X |
| 명령어 치환 `$()` | O | O | X |
| 단어 분리 | O | X | X |

---

## 정리

오늘 배운 핵심:
- 셸은 명령어를 실행하기 전에 **확장(Expansion)**을 먼저 처리
- 7가지 확장: 경로명, 틸드, 산술, 중괄호, 매개변수, 명령어 치환, 단어 분리
- `$()` = 명령어 실행, `$(())` = 수학 계산 — 헷갈리지 말기!
- `" "`(큰따옴표) = $ 계열만 허용, `' '`(작은따옴표) = 모든 확장 차단
- 중괄호 확장(`{a,b}`, `{1..5}`)은 파일/디렉토리 만들 때 정말 편함
