# Ch.25: Formatting Output

텍스트 출력을 포맷팅하는 5가지 도구: nl, fold, fmt, pr, printf

---

## 1. nl — 줄 번호 붙이기 (Number Lines)

### cat -n과의 차이

| 명령어 | 빈 줄 처리 |
|--------|-----------|
| `cat -n` | 빈 줄에도 번호 붙임 |
| `nl` | 빈 줄은 건너뜀 (기본) |
| `nl -b a` | 빈 줄에도 번호 = `cat -n`과 동일 |

### 주요 옵션

```bash
nl file.txt              # 텍스트 있는 줄만 번호
nl -b a file.txt         # 모든 줄에 번호 (빈 줄 포함)
nl -n rz -w 3 file.txt   # 001, 002, 003 형식 (0으로 채움, 3자리)
```

| 옵션 | 의미 |
|------|------|
| `-b a` | 모든 줄에 번호 (all) |
| `-b t` | 텍스트 있는 줄만 (기본값) |
| `-n rz` | 오른쪽 정렬 + 0으로 채움 (right zero) |
| `-n rn` | 오른쪽 정렬 (기본값) |
| `-n ln` | 왼쪽 정렬 |
| `-w N` | 번호 자릿수 (기본 6) |

## 2. fold — 긴 줄 접기 (가위)

지정한 폭에서 줄을 **잘라줌**. 짧은 줄은 그대로 놔둠.

```bash
fold -w 40 file.txt       # 40자에서 자름 (단어 중간에서도 잘림!)
fold -w 40 -s file.txt    # 40자, 단어 단위로 자름 (거의 항상 이걸 쓸 것)
```

**`-s`(spaces) 필수!** 없으면 단어 중간에서 뚝 잘려서 읽기 어려움.

---

## 3. fmt — 텍스트 문단 정리 (편집자)

짧게 끊긴 줄들을 **합쳐서 문단으로 재구성**해줌.

```bash
fmt -w 50 file.txt    # 50자 폭으로 문단 정리
```

### fold vs fmt 핵심 차이

```
fold = 가위    → 긴 줄을 자르기만. 짧은 줄은 그대로
fmt  = 편집자  → 짧은 줄을 합치고 지정 폭에 맞게 재배치
```

- 빈 줄 = 문단 구분자로 인식 (문단 사이는 합치지 않음)

---

## 4. pr — 인쇄용 페이지 포맷

텍스트에 헤더(날짜, 파일명, 페이지 번호)를 자동 추가.

```bash
pr file.txt          # 기본: 헤더 + 페이지 형태
pr -2 file.txt       # 2단 레이아웃
pr -3 -s"|" file.txt # 3단 + 파이프 구분자
```

실무에서 거의 안 씀. "이런 게 있다" 정도만 알면 됨.

## 5. printf — 정밀 출력 제어 (가장 중요!)

C언어의 printf에서 온 명령어. **셸 스크립트에서 필수**.

### echo와의 차이

- `echo`: 자동 줄바꿈 O
- `printf`: 자동 줄바꿈 X → `\n`을 직접 넣어야 함

### 형식 지정자 (Format Specifiers)

| 지정자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `%s` | 문자열 | `printf "%s" "hi"` | `hi` |
| `%d` | 정수 | `printf "%d" 42` | `42` |
| `%f` | 소수 | `printf "%f" 3.14` | `3.140000` |
| `%x` | 16진수 | `printf "%x" 255` | `ff` |
| `%o` | 8진수 | `printf "%o" 8` | `10` |
| `%%` | % 문자 자체 | `printf "100%%"` | `100%` |

### 폭 지정과 정렬

```bash
# 오른쪽 정렬 (기본)
printf "%10s | %5d\n" "apple" 3        #      apple |     3

# 왼쪽 정렬 (- 플래그)
printf "%-10s | %-5d\n" "apple" 3      # apple      | 3

# 0으로 채우기
printf "%05d\n" 42                     # 00042
printf "FILE_%03d.txt\n" 1 2 3        # FILE_001.txt ...

# 소수점 자릿수
printf "%.2f\n" 3.14159               # 3.14
printf "%08.2f\n" 3.14                # 00003.14
```

### 인자 반복 기능

```bash
# 형식보다 인자가 많으면 자동 반복!
printf "%-10s %5d\n" "apple" 3 "banana" 12 "cherry" 150
# apple          3
# banana        12
# cherry       150
```

### printf 형식 요약

```
%s   = 문자열       %d  = 정수        %f   = 소수
%10s = 10칸 오른쪽   %-10s = 왼쪽 정렬
%05d = 0으로 채움    %.2f = 소수 2자리
%%   = % 문자 자체
```

## 도구별 실무 빈도

| 명령어 | 빈도 | 용도 |
|--------|------|------|
| `printf` | ★★★★★ | 셸 스크립트에서 정밀 출력 |
| `nl` | ★★☆ | 줄 번호 붙이기 |
| `fold` | ★★☆ | 긴 줄 접기 |
| `fmt` | ★★☆ | 문단 정리 |
| `pr` | ★☆☆ | 인쇄용 페이지 (거의 안 씀) |

---

## 주의사항 & 흔한 실수

1. **printf는 자동 줄바꿈 없음**: `\n` 빼먹으면 다음 프롬프트가 출력에 붙음
2. **nl의 `-n rz`는 한 옵션**: `-rz`로 붙여 쓰면 에러! `-n rz`로 분리해야 함
3. **fold -s 없이 쓰면**: 단어 중간에서 잘려서 읽기 어려움. 거의 항상 `-s` 같이 쓸 것
4. **printf %d에 문자열 넣으면**: 0 출력. 헤더와 데이터를 같은 형식으로 쓰려면 `%s`로 통일
