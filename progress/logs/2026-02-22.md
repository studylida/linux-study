## 배운 명령어/개념

### Ch.15 - 파일 읽기/조회 명령어

- **cat**: 파일 전체 출력 (concatenate). `-n` 줄 번호, `-A` 숨겨진 문자 표시
- **tac**: cat 거꾸로 — 마지막 줄부터 출력
- **rev**: 각 줄의 글자 순서를 좌우 반전
- **head -n N**: 파일 앞에서 N줄 (기본 10줄)
- **tail -n N**: 파일 뒤에서 N줄 (기본 10줄)
- **tail -f**: 실시간 파일 모니터링 (follow). 로그 감시할 때 필수
- **less**: 페이지 단위 읽기. `/`검색, `q`종료
- **wc**: 줄(-l), 단어(-w), 바이트(-c) 수 세기
- **sort**: 정렬. `-n` 숫자 기준, `-r` 역순, `-k` 필드 기준, `-u` 중복 제거
- **Useless Use of Cat**: `cat file | head` 대신 `head file`로 직접 파일명 전달이 효율적
