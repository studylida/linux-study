## 배운 명령어

### Ch.4 - 파일/디렉토리 조작

| 명령어 | 기능 |
|--------|------|
| `mkdir` | 디렉토리 생성 (`-p`로 중첩 생성) |
| `cp` | 복사 (`-r`로 디렉토리 전체 복사) |
| `mv` | 이동/이름변경 |
| `rm` | 삭제 (`-r`로 디렉토리 삭제, `-f` 강제) |
| `ln` | 링크 생성 (`-s`로 심볼릭 링크) |

- 와일드카드: `*`, `?`, `[abc]`, `[!abc]`, `[[:class:]]`
- 하드 링크 vs 심볼릭 링크 차이
- 리눅스는 휴지통이 없음 → 삭제 전 `ls`로 확인

### Ch.5 - 명령어 다루기

| 명령어 | 기능 |
|--------|------|
| `type` | 명령어 종류 확인 (builtin, file, alias) |
| `which` | 실행 파일 경로 |
| `help` | 쉘 내장 명령어 도움말 |
| `man` | 매뉴얼 페이지 |
| `whatis` | 한 줄 설명 |
| `apropos` | 키워드로 명령어 검색 |
| `alias` / `unalias` | 별칭 생성/삭제 |

- 명령어의 4가지 종류: 실행 파일, 쉘 내장, 쉘 함수, 별칭
- `cd`가 내장 명령어인 이유: 현재 쉘의 디렉토리를 바꿔야 하니까
