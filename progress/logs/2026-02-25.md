## Ch.17: Package Management
- 패키지: 프로그램을 설치 가능하게 묶은 파일 (실행파일 + 설정파일 + 의존성 정보)
- 의존성: A가 동작하려면 B가 필요 → 패키지 매니저가 자동 해결
- 저장소(Repository): 패키지들이 모여있는 온라인 서버
- 데비안 계열(.deb, apt) vs 레드햇 계열(.rpm, yum/dnf)
- apt update(목록 갱신) vs apt upgrade(실제 업그레이드)
- apt remove(설정 남김) vs apt purge(완전 삭제)
- sudo 필요(install/remove/update/upgrade) vs 불필요(search/show/list)

## 연습문제
- `apt` 빠뜨리는 실수 반복 — `sudo apt [동작] [패키지]` 구조 기억할 것
- 검색(search)은 sudo 불필요

## 퀴즈
- update vs upgrade 차이 ✅
- remove vs purge 차이 ✅
- yum은 CentOS, dnf는 후속 버전 ✅ (3/3 정답!)
