## 배운 명령어/개념

### 표준 스트림

| 이름 | fd | 기본 연결 |
|------|-----|----------|
| stdin | 0 | 키보드 |
| stdout | 1 | 화면 |
| stderr | 2 | 화면 |

### 리다이렉션

| 기호 | 의미 |
|------|------|
| `>` | stdout → 파일 (덮어쓰기) |
| `>>` | stdout → 파일 (이어쓰기) |
| `<` | 파일 → stdin |
| `2>` | stderr → 파일 |
| `> file 2>&1` | stdout + stderr → 파일 |
| `&>` | 위의 축약형 |
| `\|` | stdout → 다음 명령어의 stdin |

### 핵심 포인트

- `2>&1` 순서가 핵심: `> file 2>&1` (O) vs `2>&1 > file` (X)
- `/dev/null` — 출력을 버리는 블랙홀
- `tee` — 화면 출력 + 파일 저장 동시에

### 파이프와 함께 쓰는 명령어

- `sort`, `uniq`, `wc`, `grep`, `head`, `tail`, `tee`
