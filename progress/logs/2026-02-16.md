## 배운 명령어/개념

### Ch.11 - 환경

- **셸 변수 vs 환경변수**: `VAR="값"` (현재 셸만) vs `export VAR="값"` (자식 프로세스에도 전달)
- `=` 앞뒤에 공백 없이! `VAR="값"` (O) / `VAR = "값"` (X)
- `printenv` — 환경변수 목록 / `set` — 셸 변수 + 환경변수 + 함수 전부
- **PATH**: 명령어를 찾는 디렉토리 목록, 왼쪽부터 순서대로 탐색
  - 뒤에 추가: `export PATH="$PATH:/새경로"`
  - 앞에 추가 (우선순위 높게): `export PATH="/새경로:$PATH"`
- **스타트업 파일**: 로그인 셸 → `.bash_profile`, 비로그인 셸 → `.bashrc`
- 설정 변경 후 적용: `source ~/.bashrc`

### Ch.12 - Nano 에디터

- 저장: `Ctrl+O`, 나가기: `Ctrl+X`, 저장하고 나가기: `Ctrl+X → Y → Enter`
- 잘라내기: `Ctrl+K`, 붙여넣기: `Ctrl+U`
- 찾기: `Ctrl+W`, 바꾸기: `Ctrl+\`
- bash Kill/Yank과 키가 다름 주의! (nano `Ctrl+U` = 붙여넣기, bash `Ctrl+U` = 잘라내기)
