## 오늘 배운 것

### Ch.27: Compiling Programs

1. **컴파일 4단계**: 전처리 → 컴파일 → 어셈블 → 링킹
2. **gcc 기본**: `gcc file.c -o 이름`, `-c`는 컴파일만(.o), `-Wall`은 경고 전부
3. **.h vs .c**: .h = 선언(메뉴판), .c = 구현(주방). .c가 .h를 include (반대 아님)
4. **Makefile**: 타겟:의존성 + Tab + 명령어. 변경된 파일만 다시 컴파일
5. **오픈소스 설치 3단계**: ./configure(Makefile 생성) → make(빌드) → sudo make install(설치)
