## 학습 내용: Ch.19 Networking

### 배운 명령어
- **ping**: 서버 연결 확인 (-c, -i, -s)
- **traceroute**: 경로 추적 (-m, -q)
- **ifconfig / ip**: 내 네트워크 정보 (macOS는 ifconfig)
- **netstat / ss**: 열린 포트, 연결 상태 (macOS는 netstat)
- **ssh**: 원격 접속 (-p, -i, -L 포트포워딩)
- **scp**: SSH 파일 복사 (-r, -P 대문자!)
- **wget**: 파일 다운로드 (-O, -c)
- **curl**: 만능 네트워크 도구 (-I, -s, -L, -X, -d, -H)

### 핵심 개념
- ping 안 됨 ≠ 서버 죽음 (방화벽 차단 가능성)
- 포트 = 건물의 문 번호 (IP = 주소, 포트 = 문)
- 포트 포워딩: ssh -L로 터널 뚫어서 우회 접속
- wget vs curl: 다운로드만은 wget, API/디버깅은 curl
- ssh -p(소문자) vs scp -P(대문자)

### 실습
- ping -c 5 naver.com → 100% loss (방화벽 차단 확인)
- traceroute google.com / kakao.com 경로 비교
- ifconfig | grep "inet " 으로 내 IP 확인
- curl -I로 HTTP 헤더 확인, curl -L로 리다이렉트 추적
- curl -X POST로 API 호출 테스트 (httpbin.org)
- netstat -an | grep LISTEN/ESTABLISHED 확인
- wget 설치 후 파일 다운로드 테스트
