## 오늘 배운 것

### 핵심 개념
- 마운트: 저장장치를 파일 트리에 붙이는 것
- 장치 이름: `sda`(디스크), `sda1`(파티션), `sdb1`(두 번째 디스크 첫 파티션)
- `umount` — unmount 아님! n 없음

### 주요 명령어
- `lsblk` — 블록 장치 트리
- `df -h` — 마운트 상태 + 용량
- `mount /dev/sdb1 /mnt/usb` — 마운트
- `umount /mnt/usb` — 언마운트
- `fdisk -l` — 파티션 목록
- `mkfs.ext4 /dev/sdb1` — 포맷
- `blkid` — UUID 확인
- `/etc/fstab` — 자동 마운트 설정

### macOS 실습
- `diskutil list`로 실제 디스크 구조 분석
- disk0(내부 251GB) + disk6(외장 Extreme SSD 2TB) 확인
- APFS 컨테이너 구조 이해 (disk3 = disk0s2의 논리 컨테이너)
- Extreme SSD가 "Microsoft Basic Data" (exFAT/NTFS) 포맷임 확인
