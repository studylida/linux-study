### 파트 B: comm, diff (비교하기)
- **comm**: 정렬된 두 파일의 집합 비교. 3열 출력 (파일1만/파일2만/공통)
  - 열 숨기기: `-12`(공통만), `-23`(파일1만), `-13`(파일2만)
  - 정렬 필수!
- **diff**: 줄 단위 차이 비교
  - `-u` unified 형식 = git diff 스타일 (`+`/`-`)
  - `@@` = 변경 위치 표시 (원본/수정본 줄 범위)
  - `-rq` = 디렉토리에서 다른 파일 목록만 빠르게 확인

### 파트 C: sed, awk (변환 & 가공)
- **sed**: Stream Editor. 찾아 바꾸기 끝판왕
  - `s/A/B/` 첫 매치만, `s/A/B/g` 전부 바꾸기
  - `-i` 파일 직접 수정 (먼저 화면에서 확인하는 습관!)
  - `/패턴/d` 줄 삭제, 세미콜론으로 여러 명령 연결
  - 구분자 변경: `s|A|B|g` (경로에 / 있을 때)
- **awk**: 필드 단위 처리. cut보다 강력 (연속 공백 자동 처리)
  - `$1`, `$2`, `$NF` 등 필드 변수
  - `-F:` 구분자 지정
  - 조건부 출력: `'$2 >= 80 {print $1}'`
  - `END` 블록으로 합계/평균 계산

### 복습 퀴즈 결과
- `\;` vs `+` 차이 ✅ (파일마다 vs 모아서)
- 파이프+파일명 동시 사용 ✅ (파일이 우선, 파이프 무시됨)
- `tr -s` ❌ → squeeze(중복 압축)인데 삭제(-d)와 혼동

### 흔한 실수 체험
- awk에서 큰따옴표 사용 → 셸이 $1 해석 → 줄 전체 출력
- awk 구분자 실수: `/etc/passwd`에 `-F,` 대신 `-F:` 써야 함
- 따옴표 안 닫으면 `>` 프롬프트 (Ctrl+C로 탈출)
