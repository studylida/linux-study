## 오늘 배운 것

### Ch.20 복습: `find` 깊이 제한과 안전한 삭제

1. **현재 폴더 바로 아래만 대상으로 삼기**
   - `-mindepth 1`: 시작점 `.`은 결과에서 제외
   - `-maxdepth 1`: 바로 아래 항목까지만 탐색
   - 둘을 합치면 `find . -mindepth 1 -maxdepth 1`

2. **조건으로 삭제 대상 좁히기**
   - `-type d`: 디렉토리만 선택
   - `! -name 'study'`: `study` 제외
   - `! -name '.*'`: `.git`, `.codex` 같은 숨김 폴더 제외

3. **`-exec rm -rf -- {} +` 이해**
   - `-exec`: 찾은 항목으로 명령 실행
   - `--`: 뒤의 값을 옵션이 아니라 경로로 취급
   - `{}`: `find`가 찾은 경로 자리
   - `+`: 여러 경로를 모아서 한 번에 실행
   - `\;`: 항목마다 한 번씩 실행

### 실습

삭제 전 확인:

```bash
find . -mindepth 1 -maxdepth 1 -type d ! -name 'study' ! -name '.*' -print
```

확인 후 삭제:

```bash
find . -mindepth 1 -maxdepth 1 -type d ! -name 'study' ! -name '.*' -exec rm -rf -- {} +
```

## 소감

- `find`는 삭제 명령과 같이 쓰기 전에 반드시 `-print`로 대상을 먼저 확인해야 함
- `{} +`와 `{} \;`의 차이를 알면 느린 삭제 작업이 왜 오래 걸리는지 이해하기 쉬움
- WSL의 `/mnt/c` 경로는 Windows 파일시스템이라 삭제가 느릴 수 있음
