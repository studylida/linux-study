## Ch.23: grep 완전 정복
- grep 옵션 4가지 카테고리: 매칭 방식 / 출력 제어 / 컨텍스트 / 재귀 검색
- 핵심 옵션: -i, -w, -v, -F, -E, -n, -c, -l, -o, -A/-B/-C, -r, --include/--exclude
- `-rn`은 세트로 외울 것
- `-o`로 매치 부분만 추출 (IP, 숫자 등)
- `-F`로 정규식 메타문자를 문자 그대로 검색
- `grep -vE '^#|^$'` = 주석 + 빈 줄 제외 패턴
- 연습문제 1/3 → 수정 후 3/3, 퀴즈 1/3
- 흔한 실수: 재귀 검색 시 -r 빠뜨림, 파이프 받을 때 파일명 같이 쓰면 파이프 무시됨
