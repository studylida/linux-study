## 오늘 배운 것 (재학습 - 심화)

### tr - 문자 변환/삭제
- `tr 'a-z' 'A-Z'` → 소문자를 대문자로 변환
- `tr -d '\n'` → 개행 문자 삭제
- `tr -s ' '` → 연속된 공백을 하나로 압축
- 파이프로만 입력 받음 (`echo "hello" | tr 'a-z' 'A-Z'`)
- **문자 클래스**: `[:lower:]`, `[:upper:]`, `[:digit:]`, `[:space:]`, `[:punct:]`

### tee - T자 파이프 (이중 출력)
- 파이프 흐름을 유지하면서 파일에도 동시 저장
- `ls | tee output.txt | grep ".md"`
- **tee -a**: 추가(append) 모드 — `>>`처럼 기존 내용 유지
- **tee vs `>`**: `>`는 파일에만, `tee`는 파일+화면 둘 다

### uniq - 중복 제거
- **반드시 sort 후에 사용** (인접한 중복만 제거하기 때문)
- `uniq -c`: 중복 횟수 표시
- `uniq -d`: 중복된 항목만 출력
- **`uniq -u`**: 유일한 항목만 출력 (1번만 나온 것)
- **sort -u vs sort | uniq**: `sort -u`는 단순 중복 제거, `uniq -c`로 빈도 분석하려면 반드시 `sort | uniq` 조합

### 파이프 조합 실전
- `sort | uniq` 세트로 중복 제거
- `grep "ERROR" | wc -l` 로 에러 줄 수 세기
- 단어 빈도 분석 파이프라인 단계별 해설 학습
