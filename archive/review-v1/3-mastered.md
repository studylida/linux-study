# 완벽히 암기한 용어/개념

## Ch.1~8 복습 (2026-02-13 승급)

- **cd가 내장(builtin)인 이유**: 외부 프로그램이면 자식 프로세스에서 디렉토리 변경 후 사라짐. 현재 셸 자체의 디렉토리를 바꿔야 하므로 내장 필수
- **큰따옴표 안에서 되는 확장**: `$변수`, `$(명령)`, `$((식))` — $ 계열만. 안 되는 것: `*`, `~`, `{a,b}`
- **`ls -l` 맨 앞 글자**: `d` = 디렉토리, `-` = 일반 파일, `l` = 심볼릭 링크
- **프롬프트 `$` vs `#`**: `$` = 일반 사용자, `#` = root (슈퍼유저)

## Ch.1~8 복습 (2026-02-16 승급)

- **`$()` vs `$(())`**: `$()` = 명령어 치환(명령어 실행 → 출력 결과로 대체). `$(())` = 산술 확장(수학 계산 → 결과로 대체, 정수만)

## Ch.11 복습 (2026-02-16 승급)

- **.bashrc는 비로그인 셸에서 실행**: 로그인 셸 = `.bash_profile`, 비로그인 셸 = `.bashrc`. `.bash_profile`이 `.bashrc`를 호출해서 간접 실행도 됨
- **PATH 추가는 = 재할당**: `export PATH="$PATH:/새경로"`. `>>` 리다이렉션 아님! 변수는 파일이 아니라 재할당으로 수정

## Ch.1~8 복습 (2026-02-17 승급)

- **`2>&1` 순서 문제**: `> file 2>&1` = 둘 다 file / `2>&1 > file` = stderr는 화면, stdout만 file. 핵심: 실행 시점의 stdout 위치를 따라감
- **`-`로 시작하는 파일 삭제법**: `rm -- -file.txt` 또는 `rm ./-file.txt`. 따옴표로는 안 됨 — 따옴표는 셸 확장을 막는 거고, `-` 옵션 해석은 명령어 자체의 문제
- **하드 링크 vs 심볼릭 링크 3가지 차이**: 원본 삭제 시(하드=유지, 심볼릭=깨짐) / 디렉토리(하드=불가, 심볼릭=가능) / 다른 디스크(하드=불가, 심볼릭=가능)

## 복습 (2026-02-18 승급)

- **less 조작**: `G` = 맨 끝, `g` = 맨 처음, `/단어` = 검색, `n` = 다음 결과, `q` = 나가기
- **`rm -rf` 위험한 이유**: `-r` 재귀 삭제 + `-f` 확인 없이 강제 삭제 + 리눅스에는 휴지통이 없어서 복구 불가
- **`cp -r` 없이 디렉토리 복사**: 에러 발생. `-r`(recursive)이 있어야 디렉토리 전체 복사 가능
- **bash 풀네임**: Bourne-Again Shell. 원조 셸: sh (Bourne Shell)

## Ch.1~8 복습 (2026-02-23 승급)

- **`$((15 % 4))` = 3**: 산술 확장은 정수 연산만. `%`는 나머지 연산 (3.75가 아님!)

## Ch.16 복습 (2026-02-26 승급)

- **tr -d로 삭제**: 문자를 삭제하려면 반드시 `-d` 옵션 사용. `-d` 없이 쓰면 변환(translate)이지 삭제가 아님! `tr -d 'aeiou'` = 모음 삭제

## Ch.13 복습 (2026-02-27 승급)

- **vi 확인하며 찾기/바꾸기**: `:%s/찾을것/바꿀것/gc`. 끝에 `c`(confirm)를 붙이면 하나씩 y/n 선택 가능

## Ch.19 복습 (2026-02-28 승급)

- **scp 목적지 필수**: `scp user@server:/path/file` ← 이러면 에러! 반드시 목적지 명시: `scp user@server:/path/file ./`

## Ch.18 복습 (2026-03-07 승급)

- **/etc/fstab 6개 필드**: 장치(UUID) / 마운트위치 / 파일시스템 / 옵션(defaults) / dump(0=안함) / pass(0=검사안함, 1=루트, 2=나머지)

## 복습 퀴즈 (2026-03-10 승급)

- **sort -rn으로 내림차순**: "큰 순서대로" 정렬할 때 `-r`(reverse) 필수. `sort -n`만 쓰면 오름차순(작은→큰). top N 구할 때: `sort -rn | head -N`
- **파티션 이름**: `sdb`는 디스크 전체, `sdb1`이 파티션. 장치 경로는 `/dev/sdb1`
- **scp -r 디렉토리**: 디렉토리 전체 복사 시 `-r` 필수. cp -r과 같은 이유
- **uniq**: 중복 줄 제거. **인접한** 중복만 제거하므로 반드시 `sort` 선행 필수
- **wget vs curl**: 다운로드만 → wget(-c 이어받기 편함), API 테스트/디버깅 → curl(POST, 헤더 등)

## 복습 퀴즈 (2026-03-13 승급)

- **BRE vs ERE**: BRE=`grep`(기본), ERE=`grep -E`. ERE가 `? + {} () |`를 이스케이프 없이 사용 가능
- **마운트 전 디렉토리 생성 필수**: 마운트 포인트가 없으면 `sudo mkdir /mnt/usb` 먼저! 없는 디렉토리에 mount하면 에러

## 복습 퀴즈 (2026-03-16 승급)

- **diff -u**: unified 형식. `-`=삭제, `+`=추가, `@@`=위치 표시. git diff가 이 형식
- **find -exec {} \; vs {} +**: `\;`=파일마다 하나씩 실행(느림), `+`=모아서 한 번에 실행(빠름)
- **cut vs awk 연속 공백**: cut은 각 공백을 별도 구분자로 봄, awk는 연속 공백을 하나로 자동 처리
- **^의 이중 의미**: `^abc`=줄 시작(앵커), `[^abc]`=부정(제외)
- **printf 줄바꿈 없음**: echo는 자동 `\n`, printf는 직접 `\n` 넣어야 함
